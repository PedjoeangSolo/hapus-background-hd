# Hapus Background HD

Website ringan untuk menghapus latar belakang foto langsung dari browser Android atau desktop.

## Cara menggunakan
1. Buka website melalui GitHub Pages.
2. Pilih foto.
3. Tekan **Hapus background** dan tunggu model AI dimuat.
4. Tekan **Simpan PNG transparan**.

## Catatan
- Memerlukan koneksi internet untuk memuat MediaPipe Selfie Segmentation dari CDN.
- Pemrosesan foto berlangsung di browser.
- Model paling cocok untuk manusia/selfie; hasil untuk benda lain atau detail rambut dapat bervariasi.

## GitHub Pages
Di repositori GitHub, buka **Settings → Pages**. Pada **Build and deployment**, pilih **Deploy from a branch**, pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
