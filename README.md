# Hapus Background HD — Pro

Website responsif untuk menghapus latar belakang foto di browser Android maupun desktop.

## Fitur
- Model AI background removal dari IMG.LY dengan pilihan kualitas **Medium** dan **Small**.
- Pratinjau transparansi dan latar putih/hitam/abu-abu.
- Kuas manual untuk memulihkan bagian subjek yang terpotong atau menghapus sisa background.
- Pengaturan kelembutan tepi.
- Ekspor PNG transparan dengan dimensi gambar sumber.

## Cara menggunakan
1. Buka website dan pilih foto.
2. Tekan **Hapus background AI** dan tunggu model selesai dimuat.
3. Periksa tepi gambar pada latar pratinjau yang berbeda.
4. Pilih **Pulihkan bagian subjek** atau **Hapus bagian background**, lalu sapukan kuas di hasil.
5. Atur kelembutan tepi jika perlu, lalu tekan **Simpan PNG transparan**.

## Catatan
- Membutuhkan koneksi internet untuk mengunduh library dan model AI saat digunakan. Model Medium dapat memakai data dan memori lebih banyak.
- Pemrosesan gambar berlangsung di browser perangkat.
- Rambut halus, kaca, jaring, bayangan, serta objek yang warnanya mirip dengan latar tetap dapat memerlukan koreksi manual.
- Aplikasi ini bukan jaminan hasil sempurna untuk setiap foto.
